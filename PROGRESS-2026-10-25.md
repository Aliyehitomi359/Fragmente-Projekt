# Progress / 本次进度 · 2026-10-25

## English

- Applied the Figma-adjusted workshop palette to the functional app without replacing its canvas creation or editing flows.
- Added source/fragment collection icons and counts, consistent button edges and more readable sidebar text.
- Kept archived and in-progress canvases in the central Collage Canvas workspace.
- Added compact box renaming, context-menu deletion, and additive multi-box fragment membership.
- Preserved legacy single-box data and multi-box metadata in library backups; deleting a box retains other memberships and falls back to the default box only when needed.
- Kept existing memberships when saving inspiration sessions as new boxes and when asynchronous OCR completes.
- Added proportional canvas-size previews and fixed the library tools menu clipping in narrow windows.
- Included design previews, a Figma export generator, and isolated IndexedDB membership regression tests.

Validation: `npm run build`, `node scripts/test-box-membership.mjs`, `node --test electron/library.test.cjs`.

Windows and macOS share the React UI, IndexedDB persistence, and desktop library folder scanning/import code. The GitHub Actions workflow builds macOS DMG/ZIP and Windows NSIS EXE on native runners. Windows installation and runtime behavior still need testing on a Windows computer. There is no automatic cloud or cross-device synchronization. Production and development libraries are separate; rebuilding an installer does not migrate preview data automatically.
